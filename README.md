##Tourism Website - ASP.NET Project
#Project Overview

-This is a responsive tourism website developed using ASP.NET and C#.
-The project allows users to explore different travel destinations, view destination details, and navigate through a modern user-friendly interface.

-The website was built as a learning project to improve my frontend and backend web development skills.

#Features
-Responsive website design
-Home page with attractive layout
-Destination listing page
-Dynamic destination details page
-Navigation menu
-Search functionality
-Rating section
-Clean UI design
-ASP.NET backend integration

#Technologies Used
-ASP.NET
-C#
-HTML5
-CSS3
-JavaScript
-Bootstrap
-SQL Server

#Project Structure
-Home Page
-About Page
-Destinations Page
-Destination Details Page
-Contact Page
-Register Page
-Login Page
